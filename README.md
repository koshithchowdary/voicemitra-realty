# VoiceMitra Realty

**A mobile-first, bilingual property discovery prototype for Hyderabad, India.**

## What is included

- Responsive landing page designed for mobile and desktop
- English/Telugu language toggle
- Demo property search by area, budget, and buyer purpose
- Clearly labeled fictional listings and risk notes
- Site-visit request form demonstration
- Trust-first messaging: no fake approval claims, no guaranteed appreciation, and no false booking confirmations

## View the website

After enabling GitHub Pages in the repository settings, the site should be available at:

https://koshithchowdary.github.io/voicemitra-realty/

GitHub Pages can take a few minutes to publish the first deployment.

## Publish with GitHub Pages

1. Open this repository on GitHub.
2. Go to **Settings**.
3. Under **Code and automation**, open **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**.
6. Press **Save**, then wait for the deployment to finish.

## Important prototype limitations

- All sample properties and prices are fictional. They are not offers for sale.
- This static demo does not connect to live property inventory, Telangana RERA, HMDA records, a database, WhatsApp, telephony, or an AI voice API.
- The site-visit form does not transmit or store personal details; it only shows a local demo message.
- Do not collect real customer information or represent a request as confirmed until a secure backend and a real seller/calendar confirmation are implemented.
- Before commercial use, verify property registration, sanctioned layout, title, encumbrances, and applicable legal/compliance requirements with qualified professionals.
